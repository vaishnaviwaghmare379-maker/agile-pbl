# User Story Template

Copy this template for every new story.

```
## US-XX: <Short title>

| Field        | Value                         |
|--------------|-------------------------------|
| Use Case     | UC-XX                         |
| Priority     | 🔴 High / 🟠 Medium / 🟢 Low  |
| Story Points | 1 / 2 / 3 / 5 / 8             |
| Status       | Backlog / To Do / In Progress / In Review / Done |
| Assignee     | <name>                        |

**As a** <type of user>,
**I want** <goal / feature>,
**so that** <benefit / value>.

**Acceptance Criteria**
1. Given <context>, When <action>, Then <outcome>.
2. Given <context>, When <action>, Then <outcome>.
```

## INVEST Checklist
- **I**ndependent
- **N**egotiable
- **V**aluable
- **E**stimable
- **S**mall
- **T**estable

## Example
**As a** new visitor, **I want** to register with my email and password, **so that** I can shop and track my orders.
